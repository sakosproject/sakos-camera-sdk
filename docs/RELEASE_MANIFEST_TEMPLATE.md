# Private candidate manifest format

The authorized local candidate is generated by
`scripts/verify-local-candidate.ps1` into ignored `build/private-candidate`.
`manifest.json` records the source commit and tracked dirty-state flag,
provisional coordinates, toolchain, model checksum, artifact bytes/hashes,
POM dependencies, per-module unit/lint counts, per-suite synthetic emulator counts,
strategy identities, code-only source references, minimum remaining release
requirements and a separate validation backlog.
`SHA256SUMS.txt` lists local artifact hashes. Sanitized logs and retained notices
accompany the manifest. This is a local review record, not a publication record.

Before external delivery, an owner-approved manifest additionally needs an
immutable release version, confirmed model/code/dependency distribution rights
and notices, artifact hashes and relevant verification evidence, accurate known
limitations, and the approved package registry/delivery target. Record device
coverage and independent-validation status truthfully; completion of broad
coverage or independent validation is not required for an experimental release.
The helper-site hosting record is separate and contains no SDK/model deliverables.

The website can be previewed with `python -m http.server 4173 --directory website`.
Local preview does not establish hosting, TLS, DNS or public availability.
