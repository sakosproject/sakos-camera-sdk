Open before an SDK or model release

  • Complete upstream model-weight and conversion provenance, plus owner/legal redistribution clearance.
  • Review the final dependency and license inventory and approve a release version.
  • Verify a private security-reporting path before inviting external reports.
  • Complete broader Android API and physical-camera coverage and independently assess real-world efficacy.
  • Obtain the remaining release-owner decisions.
Rights and reporting
