Verification and release status

The project has completed its authorized local implementation and candidate checks. The SDK and bundled model are not publicly available.

Local verification

The earlier full local gate recorded 185 passing JVM tests, 12 passing synthetic Android tests, zero lint errors, locally packaged Maven artifacts, and a separate minified consumer. Follow-up Android checks, artifact evidence, and one authorized live camera flow are recorded separately in the private candidate history. This status-page update did not rebuild or rerun those checks.

To repeat the consumer packaging check from the private source checkout:

PS> .\scripts\verify-local-consumer.ps1

The provisional coordinates org.sakos.camera:…:0.0.0-local are produced under build/local-maven. They are local review artifacts, not a public repository or remote install path.

Open before an SDK or model release

  • Confirm permission to redistribute the included code, exact model weights/conversion and dependencies; retain required license notices.
  • Approve an experimental version and delivery target, with artifact hashes and relevant build/consumer checks.
  • Publish accurate integration instructions, tested scope and known limitations without credentials or private media.

Validation still to do

Broader Android API/OEM and physical-camera coverage, source parity, real-world classifier efficacy and independent validation remain unverified. These are disclosed follow-up work for an experimental SDK, rather than prerequisites for this helper site. A private reporting path must be verified before inviting security reports.

Rights and reporting

The repository's Apache-2.0 license covers SakOS-owned material only. Import authorization for the model bytes does not settle their full upstream provenance or redistribution rights. No verified public or private security-reporting endpoint is configured here. This static site has no contact form, upload path, or private intake.
