Verify the local consumer path

The local-only packaging check creates four AARs with sources, POMs and retained notices, then builds a separate minified Android consumer.

PS> .\scripts\verify-local-consumer.ps1

Provisional coordinates

The script publishes org.sakos.camera:* at 0.0.0-local beneath build/local-maven. The consumer resolves Maven artifacts and does not use a project or composite dependency.

What this check establishes

  • Release AAR and source publication metadata are locally consumable.
  • A separate consumer compiles a minified build against Maven-resolved public APIs; a test-key-only variant exercises the bundled runtime on synthetic pixels.
  • Policy and model assets are included in the locally published safety artifact.

What remains pending

Current checks use synthetic benign patterns, mocks, simulated scores and an isolated emulator scene. Packaging and runtime mechanics do not establish accuracy, source parity, physical-device behavior or legal redistribution clearance. No remote publication, hosted delivery or public intake is available. The model is checked for integrity and tensor shape/dtype before use.
