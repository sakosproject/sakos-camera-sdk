Verification and release status

The project has completed its authorized local implementation and candidate checks. The source repository is publicly available for review. The SDK has no published release or remote Maven artifacts; the bundled model and its required notices are documented in the repository.

Local verification

The selected replacement passed the clean non-device gate: 185 passing JVM tests, zero lint errors, local Maven packaging, a separate minified consumer, and inspection of 24 artifacts. No emulator or device tests were run for this model. Earlier synthetic Android tests used the previous model and do not validate the replacement. A separate live camera-mechanics check is recorded in the private candidate history.

To repeat the consumer packaging check from a local source checkout:

PS> .\scripts\verify-local-consumer.ps1

The provisional coordinates org.sakos.camera:…:0.0.0-local are produced under build/local-maven. They are local review artifacts, not a public repository or remote install path.

Open before an SDK or model release

  • Approve an experimental version and delivery target, with versioned artifact hashes and relevant build/consumer checks.
  • Publish accurate integration instructions, tested scope and known limitations without credentials or private media.

Validation still to do

Broader Android API/OEM and physical-camera coverage, source parity, real-world classifier efficacy and independent validation remain unverified. These are disclosed follow-up work for an experimental SDK, rather than prerequisites for this helper site. A private reporting path must be verified before inviting security reports.

Rights and reporting

For the selected float32 replacement, the repository license review records the published redistribution conditions as satisfied, and required notices are included in the model-bearing AAR, source JAR, and Maven POM. The historical import is documented separately by hash; its bytes are excluded and its exact source weights and conversion recipe remain unresolved. This is a repository assessment, not an independent legal opinion. No verified public or private security-reporting endpoint is configured here. This static site has no contact form, upload path, or private intake.
