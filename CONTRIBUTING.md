# Contributing

Open a planning issue with text and synthetic reproduction details only. Do not
attach private media, corpus material, credentials, device identifiers, or
machine-specific logs.

Keep changes scoped to one phase in `docs/PROJECT_PLAN.md`, add or update
meaningful tests, record verification in `docs/BUILD_NOTES.md`, and avoid
changing model thresholds or toolchain versions without a separately versioned
evaluation decision. Do not add a model asset or claim a remote release until
the provenance, corpus, and device gates are satisfied.
